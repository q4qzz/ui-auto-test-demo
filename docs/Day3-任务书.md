# 第一部分：先学会「找元素」（这是核心手艺）

自动化测试 90% 的时间花在一件事上：**找到页面上的元素**。
找不到元素，后面什么都做不了。

## 工具：浏览器开发者工具（F12）

### 第 1 步：打开它

1. 手动打开 Edge，访问 <https://www.saucedemo.com>
2. 用手工账号 `standard_user` / `secret_sauce` 登录进去
3. 按 **`F12`**（或者右键页面 → 「检查」）

右边（或下方）会弹出一个面板，这就是**开发者工具**。

### 第 2 步：用「选择器箭头」点击元素

1. 在开发者工具**左上角**找一个 **箭头图标**（虚线方框里一个小指针）
2. 点它（图标会变蓝）
3. 把鼠标移到网页上的某个元素上——比如「Add to cart」按钮
4. 元素会被高亮，**点一下它**

### 第 3 步：读 HTML

点完之后，开发者工具的 **Elements（元素）** 面板会自动滚到那段 HTML，并高亮它。长这样：

```html
<button id="add-to-cart-sauce-labs-backpack"
        name="add-to-cart-sauce-labs-backpack"
        class="btn btn_primary btn_small btn_inventory"
        data-test="add-to-cart-sauce-labs-backpack">Add to cart</button>
```

**你要从里面挑一个属性，用来定位这个元素。**

### 第 4 步：选哪个属性？—— 定位器优先级

这是**面试必问**的。优先级从高到低：

| 优先级 | 属性 | 写法 | 为什么 |
|---|---|---|---|
| ⭐⭐⭐⭐⭐ | `id` | `(By.ID, "login-button")` | 唯一、稳定、最快 |
| ⭐⭐⭐⭐ | `data-test` | `(By.CSS_SELECTOR, "[data-test='checkout']")` | 开发专门为测试留的属性，最稳定 |
| ⭐⭐⭐ | `class` | `(By.CLASS_NAME, "shopping_cart_badge")` | 可能不唯一，样式改版会变 |
| ⭐ | `xpath` | `(By.XPATH, "//div[3]/button")` | **尽量别用**，页面一改就断 |

> 💡 **面试标准答案**：
> 「优先用 id，其次是开发为测试预留的 data-test 属性，尽量避免用样式 class 和绝对路径 xpath——
> 因为前者会被样式改版影响，后者会被页面结构变化影响，都会让用例变得脆弱。」

# 第二部分：你的编程任务

## 任务 A：扩展商品列表页（`pages/inventory_page.py`）

打开这个文件，往下拉到 **「TODO 区域」**，有 4 个空要你填：

| 编号 | 要做什么 |
|---|---|
| TODO 1 | 补全 3 个元素定位器（加购按钮、购物车角标、购物车图标） |
| TODO 2 | 实现 `add_first_n_to_cart(n)` —— 把前 n 件商品加入购物车 |
| TODO 3 | 实现 `cart_badge_count` —— 返回角标上的数字 |
| TODO 4 | 实现 `open_cart()` —— 点进购物车页 |

**提示（不直接给答案）：**

- **加购按钮**有 6 个，它们的 `data-test` 都以 `add-to-cart` 开头。
  用 CSS 选择器匹配"以某段开头"的语法是 `[data-test^='开头文字']`
- **购物车角标**：加购【之前】它根本不存在；加购【之后】才出现。
  所以要用 `find_elements`（复数）而不是 `find_element`，否则会报错
- 角标上的 `.text` 是**字符串** `"2"`，不是数字 `2`。要返回数字记得 `int()`
