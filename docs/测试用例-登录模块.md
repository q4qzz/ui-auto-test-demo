## 一、需求说明

登录页包含三个元素：

| 元素 | 说明 |
|---|---|
| 用户名输入框 | Username |
| 密码输入框 | Password |
| 登录按钮 | Login |

网站登录页上公示了若干测试账号，其中包含**一个被锁定的账号**。
（第一步：自己去网站上把它们抄下来，不要抄别人的。）

## 三、自查清单

填完之后，对着这张表逐条检查：

- [ ] 我是不是**先去网站上核实了真实账号**，而不是凭印象写的？
- [ ] 每条用例是不是**只验证一个点**？
- [ ] 有没有覆盖**被锁定的账号**？（这是一个典型的异常场景，面试常问）
- [ ] 有没有覆盖**用户名和密码都为空**的情况？
- [ ] 有没有考虑**密码错误**（用户名对、密码错）？
- [ ] 每条用例的"预期结果"是不是**明确到可以判断通过/失败**？
  - ❌ 不合格：`登录失败`
  - ✅ 合格：`页面提示 Username and password do not match，且停留在登录页`
- [ ] 我是不是**把每条用例都拿到网站上实际执行了一遍**？
